## Replacement Instructions for Salon Owners
To replace these stock photographs with genuine photographs of your salon premises, team, and client haircuts:
1. Save your photos in `/public/images/` using standard web formats (`.webp`, `.jpg`, `.png`).
2. Update the corresponding image path in your salon profile (`/src/config/salons/smooth-cut-hair-studio.ts`).
3. Set `showStockNotice: false` in the config features when all photos represent genuine salon work.
